# الصفحة الشخصية — IbnKabed

بديل دائم لصفحة `about.me/ibnkabed`، يُستضاف مجانًا على GitHub Pages.

**الرابط:** https://ibnkabed.github.io

كل شيء في ملف واحد: `index.html` — لا أدوات بناء ولا اعتماديات. أي تعديل يُحفظ ثم يُرفع، فيظهر خلال دقيقة.

---

## تغيير الخلفية

**من الصفحة نفسها:** زر لوحة الألوان في الزاوية العليا — سبع خلفيات مطفية، والاختيار يُحفظ في المتصفح لكل زائر على حدة.

**تغيير الافتراضية للجميع:** في `index.html` ابحث عن `DEFAULT_THEME` وغيّر قيمته إلى أحد: `auto` أو `sand` أو `stone` أو `sage` أو `mist` أو `clay` أو `night`.

**إضافة خلفية جديدة:** موضعان فقط:

1. في قسم `١) الخلفيات والألوان` أعلى `<style>` — انسخ سطرًا كاملًا وغيّر اسمه وألوانه:

   ```css
   [data-theme="اسم-جديد"] { --bg:#...; --bg-2:#...; --card:#...; --text:#...; --muted:#...; --line:#...; --ink:#...; --shadow:0 0 0; }
   ```

   | المتغير | معناه |
   |---|---|
   | `--bg` و `--bg-2` | لونا الخلفية (تدرّج رأسي بينهما) |
   | `--card` | خلفية البطاقة |
   | `--text` | لون النص الأساسي |
   | `--muted` | النص الثانوي وحدود الأيقونات |
   | `--line` | لون الخطوط والفواصل |
   | `--ink` | لون التمرير على الأيقونات عديمة اللون (X، Threads، GitHub) |
   | `--shadow` | لون الظل بصيغة RGB بمسافات، مثل `26 22 16` |

2. في قسم `٥) قائمة الخلفيات` أسفل الملف — أضف سطرًا إلى `THEMES` بالاسم نفسه:

   ```js
   { name: "اسم-جديد", dot: "#لون-الدائرة", label: "الاسم المعروض" },
   ```

**خلفية بصورة:** في `body` استبدل `background-image` بـ `url("assets/bg.jpg")` مع `background-size: cover`.

## تعديل الروابط

كل رابط سطر `<li>` واحد داخل `<ul class="links">`. لتغيير حساب: عدّل `href`. لحذف رابط: احذف السطر. والترتيب في الملف هو الترتيب في الصفحة.

لإضافة موقع جديد: انسخ سطرًا، غيّر `href` و `aria-label` و `title`، وضع مسار أيقونته من [simple-icons](https://simpleicons.org) داخل `<path d="...">`.

في كل سطر متغيّران:

- `--brand` لون التمرير على الأيقونة (اتركه فارغًا ليأخذ لون النص).
- `--k` معامل المقاس. الأيقونات نحيلةٌ وعريضة وثقيلةُ الحبر وخفيفته، فلو رُسمت كلها بمقاس واحد بدت متفاوتة. المعامل محسوب لكل شعار من نسبة عرضه إلى ارتفاعه ومن كثافة حبره، والمقاس الأساس `--glyph` في `.links`.

وأغلفة الشعارات عولجت على حالين:

- **نُزع غلافها** حيث كان الغلاف قرصًا أو فقاعة لا يضيف شيئًا فوق القالب الدائري: واتساب صار سمّاعة، وتيليجرام طائرة، وفيسبوك حرف `f`، وIMDb حروفًا بلا صندوق، وGitHub قطًّا بلا قرص.
- **بقي غلافها وكُبِّر** حيث كان الغلاف جزءًا من هوية الشعار: مربّع إنستغرام ومستطيل يوتيوب. وكبرا حتى كادا يلامسان القالب، فيقرأهما البصر حلقتين متراكزتين لا إطارًا داخل إطار.

فإن أضفت شعارًا له غلاف، اختر له أحد الحالين.

## تعديل الصورة والاسم

- **الصورة:** استبدل `assets/profile.jpg` بصورة مربّعة (٥١٢×٥١٢ تكفي)، وجدّد `assets/favicon.png` (٦٤×٦٤) إن أردت.
- **الاسم والوصف:** في `<h1>` و `<p class="role">`، ثم حدّث وسوم `og:` و `twitter:` في `<head>` ليطابقها ما يظهر عند مشاركة الرابط.

## المعاينة محليًا قبل الرفع

```bash
python -m http.server 8777
```

ثم افتح `http://127.0.0.1:8777`.

## ربط نطاق خاص لاحقًا

إن اشتريت نطاقًا (مثل `ibnkabed.com`): أنشئ ملف `CNAME` في جذر المستودع يحتوي على اسم النطاق فقط، ثم وجّه سجلات DNS إلى GitHub Pages. الرابط `ibnkabed.github.io` يبقى عاملًا بعدها.
